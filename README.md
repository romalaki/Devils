# Devils

Тестовий застосунок на Unity, що при старті відкриває сторінку у вбудованому WebView. Для роботи з WebView я використовую **UniWebView**.

---

У цьому проєкті я використовую UniWebView. Коли я працював у TraffBraza, сеньйори навчили мене базовому використанню та налаштуванню цього плагіна. Також використовую власний невеличкий скрипт SafeArea, який написав власноруч для коректної взаємодії із застосунком.

Дякую за це завдання!
